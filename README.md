# Inventory & Supply Chain Management Dashboard 

**Live Dashboard / Snapshot:** 
![Dashboard Preview](https://github.com/jaydip-lakum/Inventory-Management-PowerBI/blob/main/Inverntory_Management_Dash...jpg)

##  Quick Overview
An interactive Power BI dashboard analyzing **500 records** of supply chain data. Built to help procurement teams track inventory health, monitor supplier performance, and instantly identify stockout risks.

##  Tech Stack
**Power BI | Power Query | Data Modeling | Business Intelligence**

##  Key Business Insights
- **Locked Capital:** Currently, **AED 48.04M** worth of inventory is locked in the warehouse.
- **Urgent Reorders:** Successfully isolated **108 products** that have fallen below their critical reorder thresholds and need immediate restocking.
- **Top Performers:** **Stationery** holds the highest closing stock (22K), while **Supplier E** is the top vendor, driving 32K in unit sales.
- **Sales Growth:** Cumulative Year-To-Date (YTD) sales show a strong upward trend, peaking at **45.2K units** by December.

##  Key Features & Skills Demonstrated
- **Smart Reorder Filtering:** Built custom logic to hide healthy stock, automatically highlighting only the items that require urgent procurement.
- **Dynamic KPIs:** Developed performance metrics for Total Inventory Value, Stock Turnover Ratio, and YTD Sales to track business health.
- **Data Transformation (ETL):** Cleaned raw data, established table relationships, and generated calculated columns using Power Query to build a robust data model.
